# Zackjad — Visual Inspiration & Reels

A modern, high-performance visual discovery and reels platform built with React 18, TypeScript, Vite, and Tailwind CSS.

## Features
- **Visual Pin Discovery**: Categorized feed with masonry grid layout, image inspection, like/save reactions, and comment system.
- **Pin Publishing**: Creators can upload and post visual pins with titles, image URLs, categories, and descriptions.
- **Short Video Reels**: 9:16 vertical video feed with loop playback, likes, and repost metrics.
- **Direct Messaging**: In-browser messaging between creators and platform members.
- **Instant Gmail Authentication**: Login and registration with Gmail without OTP requirement, as well as credentials login.
- **Dynamic Developer Profile**: The Developer view automatically updates in real time whenever the Admin updates their profile name, avatar, or bio.
- **Admin Management Centre**:
  - **Site Management**: Content moderation and pin removal.
  - **Payment Management**: Revenue tracking, MRR metrics, transaction logs.
  - **Link Credit Card**: Merchant payout card linking with status indicators, currency selection (KES/USD), and card management.
  - **User Management**: Search users, toggle Administrator privileges, grant/revoke Pro status, and account deletion.
